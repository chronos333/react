# React Vite SAEP

Projeto desenvolvido para a atividade de introdução ao React utilizando Vite.

## Tecnologias

* React
* Vite
* JavaScript
* Node.js
* npm

## Requisitos

Antes de executar o projeto, é necessário possuir instalado:

* Node.js
* npm
* Git

## Instalação

Clone o repositório e acesse a pasta do projeto:

```bash
git clone URL_DO_REPOSITORIO
cd react-vite-saep
```

Instale as dependências:

```bash
npm install
```

## Execução

Para iniciar o servidor de desenvolvimento:

```bash
npm run dev
```

Após iniciar o servidor, acesse no navegador o endereço apresentado pelo terminal, normalmente:

```text
http://localhost:5173
```

## Estrutura principal

```text
react-vite-saep/
├── public/
├── src/
├── index.html
├── package.json
├── package-lock.json
└── vite.config.js
```

### src

Contém os componentes, estilos e demais arquivos responsáveis pela aplicação React.

### public

Contém arquivos estáticos públicos utilizados pela aplicação.

### package.json

Contém informações do projeto, scripts e dependências.

### vite.config.js

Arquivo responsável pelas configurações do Vite.

### index.html

Documento HTML utilizado como ponto de entrada da aplicação.

## Scripts disponíveis

### Desenvolvimento

```bash
npm run dev
```

Inicia o servidor de desenvolvimento do Vite.

### Build

```bash
npm run build
```

Gera a versão de produção da aplicação.

### Preview

```bash
npm run preview
```

Executa uma prévia da versão de produção gerada pelo build.

## Git

O primeiro commit do projeto foi realizado com a mensagem:

```text
chore: inicializa projeto React com Vite
```

## Objetivo da atividade

A atividade tem como objetivo criar um projeto React utilizando Vite, compreender sua estrutura inicial, executar a aplicação no ambiente de desenvolvimento e utilizar Git para realizar o primeiro versionamento do projeto.
